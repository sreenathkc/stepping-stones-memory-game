STEPPING STONES - a memory path game for Anbernic H700 handhelds (RG35XX Plus/H/SP/Pro, RG40XX...)

INSTALL (any custom firmware with a "ports" folder: ROCKNIX, muOS, Knulli...)
 1. Copy SteppingStones.zip to the SD card and unzip it into the ports folder, e.g.
      ROCKNIX: /storage/roms/ports/      (SD card: roms/ports)
      others : roms/ports  or  /roms/ports
    You should end up with:  ports/Stepping Stones.sh  and  ports/steppingstones/
 2. Refresh the game list (or restart the frontend). "Stepping Stones" appears under Ports.

Everything the game needs is inside the steppingstones folder; your progress (save.txt) is
kept there too, so copying the folder to another device also copies your badges.
Controls: d-pad move/step, A play/confirm, B back, L1/R1 difficulty, Start menu (sounds, music...).
Select+Start quits.
Credits: font Fredoka (SIL OFL, see assets/OFL.txt); inspired by a famous YouTube
tile-pattern memory challenge.
